# Gayatri Portfolio

Personal portfolio website for Gayatri Jarajapu, a Computer Science undergraduate focused on AI/ML and full-stack development.

## Live Site

[Portfolio Website](https://portfolio-gayatri-jet.vercel.app/)

## About

This portfolio showcases my profile, technical skills, AI/ML projects, and contact details. It is built with a modern Vite + React setup and includes smooth animated sections for skills and projects.

## Featured Projects

- **Plant Disease Detection**  
  CNN-driven crop health system for diagnosing plant leaf diseases from uploaded images.

- **Automatic Image Caption Generator**  
  AI-powered image captioning app using YOLOv8, BLIP, multilingual translation, text-to-speech, and Streamlit.  
  [Live App](https://automatic-image-caption-generator.streamlit.app/)

- **AI-Powered Document Analysis & RAG Platform - DocuMind AI**  
  Full-stack AI application for PDF upload, summarization, information extraction, and RAG-based question answering using React, FastAPI, Gemini, FAISS, and PostgreSQL.

## Getting Started

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
